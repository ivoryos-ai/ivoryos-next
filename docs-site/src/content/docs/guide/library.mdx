**Load to Designer** asks first if the canvas holds unsaved changes.

## Versions

<Shot name="library-versions" alt="The version history of a workflow" />

- Opening an older version rolls nothing back by itself. Going back is *open v1, then Save*.
- Each version records the **deck version** it was written on, so a workflow from before a driver
  update says so.

## Tags

<Shot name="library-tags" alt="Adding a tag to a workflow" />

Tags rather than folders, because a workflow often belongs to two groups at once (a screen *and* a
calibration) and its name is its identity everywhere. Tags ignore capital letters.

## Which workflows still run here

Every workflow is checked against the deck's current instruments. One that names a method the deck
no longer has, or an argument that no longer exists, carries a badge and sorts last when
**working first** is ticked. Load it: the Designer marks exactly the steps to fix.

<Aside type="note" title="Links and deletion">
A workflow that others **link** to cannot be deleted while they do, and saving a change to it warns
you that they will change too. A workflow that was only ever **copied** has no such ties. See
[Logic and saved workflows](/guide/designer/#logic-and-saved-workflows).
</Aside>
