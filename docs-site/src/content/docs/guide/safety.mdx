A driver says what an instrument *can* do. What a bench *allows* is the lab's decision, so it is
set here, outside the drivers, and survives a driver update. Everything is checked twice: when a
run is submitted, and again just before each call is sent.

## Limits

<Shot name="safety-limits" alt="The Safety page: limits for the reactor" />

- A limit is a lowest and highest value, a list of allowed values, or a position on a tray.
- A unit alone, with no bounds, is a valid limit. The unit then shows wherever that value appears.
- A field the driver already types as a list of choices accepts only those. A limit can only
  narrow it.
- **every *Class*** applies the limit to every instrument built from that driver.
- A step that leaves an argument at its default is checked at that default.

Once saved, the Run page marks a value outside its limit as you type:

<Shot name="run-once-guard-hint" alt="The Once tab with a value above its limit marked in red" />

And the run is refused:

<Shot name="run-refused" alt="A run refused by a safety limit" />

<Aside type="note" title="A refused step is a failed step">
During a run, a value the guard refuses pauses the run like a driver error: the pop-up names the
limit, and you retry with other values, skip, or stop. Nothing is ever clamped silently.
</Aside>

## Trays

<Shot name="safety-trays" alt="The Trays tab: a 4 by 6 vial rack with one blocked position" />

A field limited to a tray takes only its positions, exactly as named, and gets a picker on the Run
page. A liquid handler's labware appears here by itself, from the driver's worktable.

## States

<Shot name="safety-states" alt="The States tab: a state set by a call" />

No two drivers describe the deck the same way, so a state is defined here and mapped onto them. A
state set by calls is remembered across restarts. It is unknown, which blocks, only when nothing
has ever set it or a call that sets it did not finish.

## Rules

<Shot name="safety-rules" alt="The Rules tab: no dispensing into a hot vial" />

A rule can compare an argument of the call, a reading from an instrument, a state, or the last
value sent through this deck. Anything that cannot be determined **blocks**: a reading that fails,
a state nothing has set.

**Blocked** lists what the guard refused recently, and why.

The file behind this page (`safety.json` in the deck's data folder) is described in
[Safeguards](/dev/extend/safeguards/).
