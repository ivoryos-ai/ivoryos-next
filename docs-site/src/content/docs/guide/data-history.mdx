Data History keeps every run the deck has made.

<Shot name="data-history-list" alt="The list of runs, with search, sort and filter" width="narrow" />

The trash on a card deletes that run. A run still going is refused.

## A run

<Shot name="data-history-run" alt="A finished run: timeline, data table and exports" />

Hover a bar on the timeline for the step's details. The slowest steps are named under it.

## Its steps

<Shot name="data-history-steps" alt="A run's steps, with their arguments and results" />

Each step shows its instrument and method, the arguments as sent, the result, how long it took,
and the error if it failed.

| Colour | Means |
|---|---|
| green | completed |
| amber | completed with issues: a step failed and was skipped, or was retried |
| hollow grey ring | not run: a row or cleanup the run never reached after a stop |
| red | error |

## Exports

| Button | File |
|---|---|
| **Data** | CSV of the data table: one row per sample or trial, a column per input and per saved output |
| **Log** | CSV of every step with its arguments, result, status and times |
