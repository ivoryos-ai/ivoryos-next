**Assistant**, in the navigation on every page, opens a panel beside the page.

<Shot name="assistant" alt="The Assistant panel open beside the Designer" />

| Mode | You ask for | You get |
|---|---|---|
| **Ask** | "Which run had the best yield?" | an answer worked out from the run records |
| **Workflow** | a protocol in a sentence or two | a draft made of this deck's own methods, to put on the canvas |
| **Safety** | "Never heat above 120 °C" | limits and rules, opened on the Safety page as an unsaved draft |

Every draft is checked before you see it: unknown instruments or methods, missing or mistyped
arguments, values outside a field's choices or a safety limit, `#variables` nothing produces. The
model is told what was wrong and tries again, up to three times.

<Aside type="caution" title="Nothing the assistant writes takes effect by itself">
A draft is a **proposal**. It reaches the canvas only when you put it there, it is saved only when
you save, and it runs only when you press Run. The same holds for an outside agent talking to the
deck through its MCP server.
</Aside>

## Models

The sliders icon at the top of the panel chooses the provider, the endpoint, the key and the
model. The key is kept on the deck's computer and never shown again.

| Provider | Notes |
|---|---|
| **Ollama** (default) | A model on this computer. No key, and nothing leaves the building. |
| **OpenAI-compatible** | Any hosted model with that API. Give the endpoint and the key; **refresh** lists the models. |
| **Claude** | The deck needs `pip install 'ivoryos-edge[claude]'`. Paste a key, or leave it empty if `ANTHROPIC_API_KEY` is set where the deck runs. |

Using Claude Desktop or Claude Code as the agent instead, and what the checker looks at, is in
[Agents and MCP](/dev/extend/agents-and-mcp/).
