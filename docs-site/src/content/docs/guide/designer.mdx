The Designer is where a workflow is built: steps dragged from the toolbox onto the canvas, in the
order they run.

<Shot name="designer-overview" alt="The Designer with the example workflow: toolbox, phases, a step, and the run buttons" />

## Start from an empty canvas

<Shot name="designer-empty" alt="The Designer with an empty canvas" />

- A dropped step opens ready to fill in. Drop it between two steps to put it there.
- The search box filters the toolbox. The button beside `#auto` folds every group to one line.

## Fill in a step

<Shot name="designer-step" alt="A step opened for editing: its values, the name its result is saved under, and its controls" />

Closed, a step is one line that reads like its call, and each kind of value looks different:

| On the line | Means |
|---|---|
| `volume_ml=0.2` in black | a value you typed |
| `flow_rate=2` in grey | the driver's default, untouched |
| `setpoint_c=#temperature_c` | left open: asked for when the workflow runs |
| an amber `?` | a required value still missing |
| `→ absorbance_312` | the result is saved under this name |

- Click any value to open the step. Click outside it, or press <kbd>Esc</kbd>, to close.
- The same `#name` in two steps is the same value. While you type `#`, the editor suggests the
  names saved by the steps *before* this one.
- A method that returns several fields offers one name per field.
- Drag a step to reorder it. **⋯** duplicates or disables it; a disabled step stays,
  greyed, and does not run.

## Name, save and export

<Shot name="designer-header" alt="The Designer's header: name, New, Save and the More menu" />

- An **Unsaved** badge appears beside the name whenever the canvas differs from the saved version.
- The first save asks for a name. Every later save adds a version to the [Library](/guide/library/).
- If other workflows link to this one, saving says so first and offers another name.

## Prep and Cleanup

<Shot name="designer-prep" alt="The Prep phase open, with the steps that run once before the first sample" />

To move a step to another phase, drag it over that phase's tab and hold: the canvas switches and
you drop the step where it belongs. Let go on the tab itself and it goes to the end of that phase.

## Logic and saved workflows

<Shot name="designer-logic" alt="A workflow with an If block, and the toolbox's Logic steps and Copy or Link switch" />

| Logic step | What it does |
|---|---|
| **Wait** | Pauses for a number of seconds. Stop ends it at once. |
| **User input** | Pauses the run and shows a message on every page. With a variable name it asks for a value (text, whole number, decimal, yes/no) and saves it; without one it is a plain pause with **Continue**. |
| **Set variable** | `name = value`: a number, `True`/`False`, text, or a calculation over names saved so far (`volume * 2`, `round(mass / 3, 2)`). |
| **If / else** | Runs the steps down to **Else** when the condition holds, the ones down to **End if** otherwise. |
| **While loop** | Repeats the steps down to **End while** as long as the condition holds. |
| **Comment** | Writes a note into the run log, like `print()`. |

A condition or a calculation is written over saved names **without** the `#`:
`absorbance_312 > 1.5`, `yield_percent < 40 and attempt < 3`. A message or prompt may contain
`#name` anywhere in its text, and the value is filled in when the step runs.

**Reusing a saved workflow.** The Workflows group lists every saved workflow except the one being
edited.

| | Copy | Link |
|---|---|---|
| What lands on the canvas | the workflow's steps, as a group | one step |
| Tied to the saved workflow | no, they are yours to edit | yes, pinned to the version it had |
| When the saved workflow changes | nothing happens | the link keeps its version until you update it; **Detach** turns it into a copy |

A linked workflow used as a step runs its **Main** steps only. Its own Prep and Cleanup run when
it is the whole run: on its own, or as a [stage](/run/stages/).

**Groups** are for tidiness: **Select** several consecutive steps and group them, and they
collapse, move and delete together. A group tracks nothing.

## When a step is wrong

Warnings appear above the step, never behind a click: a method the deck no longer has, a missing
required value, text in a number field, a value outside a [safety limit](/guide/safety/).
