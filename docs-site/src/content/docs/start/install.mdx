There are two ways to run IvoryOS. **The desktop app** is the one to pick unless you already have a
Python workflow of your own: it manages Python, your decks and driver installs for you.

## The desktop app

<Steps>

1. Download the installer for your computer (always the newest version):

   | Windows | macOS (Apple silicon) | Linux |
   |---|---|---|
   | [IvoryOS-Setup.exe](https://github.com/ivoryos-ai/ivoryos-next/releases/latest/download/IvoryOS-Setup.exe) | [IvoryOS-arm64.dmg](https://github.com/ivoryos-ai/ivoryos-next/releases/latest/download/IvoryOS-arm64.dmg) | [IvoryOS.AppImage](https://github.com/ivoryos-ai/ivoryos-next/releases/latest/download/IvoryOS.AppImage) |

   Release notes and earlier versions are on the
   [Releases page](https://github.com/ivoryos-ai/ivoryos-next/releases).

2. Open it:

   <Tabs syncKey="os">
     <TabItem label="Windows">
       Run the installer. It is signed. Windows can still show "Windows protected your PC" for a
       newly signed app until it has built up a reputation: choose **More info**, then **Run anyway**.
     </TabItem>
     <TabItem label="macOS">
       Open the `.dmg` and drag IvoryOS to Applications. The app is signed and notarized by Apple,
       so it opens like any other app.
     </TabItem>
     <TabItem label="Linux">
       Make the file executable and run it:
       ```bash
       chmod +x IvoryOS.AppImage && ./IvoryOS.AppImage
       ```
     </TabItem>
   </Tabs>

3. Wait for the first launch to finish. It downloads a Python of its own, so it needs an internet
   connection and takes about a minute. Nothing is installed into the app bundle itself: Python and
   every driver live in the app's data folder (see [Where things are on disk](/desktop/decks-and-profiles/#where-things-are-on-disk)).

</Steps>

You land on the welcome page:

Continue with [Try the example](/start/try-the-example/).

## The edge server alone (pip)

The deck is a plain Python package, `ivoryos-edge`, with its web interface inside. Use it directly
when you already have a script that creates your instruments, or on a machine where you want no
desktop app (Python 3.10 or newer):

```bash
pip install ivoryos-edge
```

To work on IvoryOS itself, see [Development setup](/dev/internals/development-setup/).

Then end your script with `ivoryos_edge.run(__name__)` and run it:

```python
import ivoryos_edge
from my_lab import SyringePump

pump = SyringePump(port="COM3")  # each object becomes an instrument

ivoryos_edge.run(__name__)       # http://localhost:8080
```

The page opens at `http://localhost:8080` in any browser on that computer. Everything in the user
guide applies; only the desktop app chapters do not. [Start a deck](/dev/instruments/start-a-deck/)
covers deck files, ports, data folders and the command line.

<Aside type="note" title="Python version">
The edge needs Python 3.10 or newer. The desktop app brings its own, so this only matters for a pip
install.
</Aside>
