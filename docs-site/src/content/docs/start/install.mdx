There are two ways to run IvoryOS. **The desktop app** is the one to pick unless you already have a
Python workflow of your own: it manages Python, your decks and driver installs for you.

## The desktop app

<Steps>

1. Download the installer for your computer from the
   [Releases page](https://github.com/ivoryzh/ivoryos-next/releases).

   | Windows | macOS (Apple silicon) | Linux |
   |---|---|---|
   | `IvoryOS-Setup-<version>.exe` | `IvoryOS-<version>-arm64.dmg` | `IvoryOS-<version>.AppImage` |

2. Open it. The app is not code-signed yet, so your computer warns the first time:

   <Tabs syncKey="os">
     <TabItem label="Windows">
       SmartScreen says "Windows protected your PC". Choose **More info**, then **Run anyway**.
     </TabItem>
     <TabItem label="macOS">
       Open the `.dmg` and drag IvoryOS to Applications. If macOS says the app "is damaged" or
       "can't be opened", run this once in Terminal:
       ```bash
       xattr -cr /Applications/IvoryOS.app
       ```
     </TabItem>
     <TabItem label="Linux">
       Make the file executable and run it:
       ```bash
       chmod +x IvoryOS-*.AppImage && ./IvoryOS-*.AppImage
       ```
     </TabItem>
   </Tabs>

3. Wait for the first launch to finish. It downloads a Python of its own, so it needs an internet
   connection and takes about a minute. Nothing is installed into the app bundle itself: Python and
   every driver live in the app's data folder (see [Where things are on disk](/desktop/decks-and-profiles/#where-things-are-on-disk)).

</Steps>

You land on the welcome page, which offers three things: **Try the example** (a simulated lab,
nothing to plug in), **Add a deck** (your own instruments) and the Automation Hub. Continue with
[Try the example](/start/try-the-example/).

## The edge server alone (pip)

The deck is a plain Python package, `ivoryos-edge`. Use it directly when you already have a script
that creates your instruments, or on a machine where you want no desktop app. The package carries
its web interface, which is built from the repository's frontend, and it is not on PyPI yet, so
build it from a checkout (Python 3.10 or newer, Node.js 22 and [uv](https://docs.astral.sh/uv/)):

```bash
npm install && npm run build:edge
pip install edge_server/dist/ivoryos_edge-*.whl
```

or, to work on IvoryOS itself, `pip install -e ./edge_server` after `npm --prefix frontend run build`.

Then end your script with `ivoryos_edge.run(__name__)` and run it:

```python
import ivoryos_edge
from my_lab import SyringePump

pump = SyringePump(port="COM3")  # each object becomes an instrument

ivoryos_edge.run(__name__)       # http://localhost:8080
```

The page opens at `http://localhost:8080` in any browser on that computer. Everything in the user
guide applies; only the desktop app chapters do not. [Start a deck](/dev/instruments/start-a-deck/)
covers deck files, ports, data folders and the command line.

<Aside type="note" title="Python version">
The edge needs Python 3.10 or newer. The desktop app brings its own, so this only matters for a pip
install.
</Aside>
