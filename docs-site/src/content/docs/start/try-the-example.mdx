The example deck is a simulated chemistry bench: three syringe pumps, a heater-stirrer (the
reactor), a balance, a UV-Vis probe and an HPLC. Nothing to plug in, and simulated time is
compressed, so an hour's hold takes about a second.

## Start it

- **Desktop app:** choose **Try the example** on the welcome page (or **Add a deck → Try the
  example** later). The deck opens by itself when it is ready.
- **From a source checkout:** `python example/demo.py`, then open `http://localhost:8080`.

<Shot name="launcher-welcome" alt="The desktop app's welcome page, with Try the example" />

Either way you land on the **Designer**.

## Build a workflow

Three steps: put a vial in the reactor, heat it to a temperature you choose when you run, and read
the temperature back.

<Steps>

1. Find **load vial** and drag it onto the canvas.

   <Shot name="first-drag" alt="Dragging the load vial step from the toolbox onto the canvas" />

2. Do the same with **set temperature**. Leave its value open.

   <Shot name="first-variable" alt="The set temperature step with #temperature_c typed as its setpoint" />

3. Add **read temperature**, and save what it returns.

   <Shot name="first-result" alt="The read temperature step saving its result as temperature" />

4. Name the workflow and save it.

   <Shot name="first-save" alt="The named workflow, saved, with the Configure button" />

</Steps>

## Run it

<Steps>

1. **Configure** opens the Run page. Choose **Once**, give the temperature, and run.

   <Shot name="first-run" alt="The Once tab with temperature_c set to 60" />

2. Open **Data**. The run is at the top of the list.

   <Shot name="first-data" alt="The finished run in Data History: the value given and the temperature read back" />

</Steps>

That is the whole loop: steps from the toolbox, a value left open, a result saved, a run, a
record.

## A fuller workflow to explore

The rest of this guide uses a Suzuki coupling screen on the same deck: charge a vial from three
pumps, stir and heat it, then measure absorbance and yield. The yield really depends on the
temperature, the catalyst and the time, so there is an optimum for an optimizer to find.

Download [suzuki-coupling-screen.json](/examples/suzuki-coupling-screen.json), then in the Designer
choose **⋯ → Import JSON…** and **Save**.

<Shot name="designer-overview" alt="The Suzuki coupling screen workflow in the Designer" />
