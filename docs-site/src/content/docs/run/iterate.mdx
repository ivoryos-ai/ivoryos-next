**Iterate** runs the workflow once per row of a table: one column per open value, one row per
sample.

<Shot name="run-iterate" alt="The Iterate tab with four samples filled in" />

- **Add Row** adds a row, the handle on the left drags rows into order, the trash removes one.
- **Import CSV** takes a file whose header matches the column names.
- An empty cell offers **None** (send no value) or **Default** (leave it to the driver), where the
  argument allows it.
- A column that holds a position on a tray or a well on a plate gets a picker: pick the positions
  in visiting order and the column fills, one row each.
- **Stop early when a sample reaches a target** ends the run after the first sample that meets it,
  cleanup included, as a success. The rows left are marked *not run*.

## Per-sample and per-batch steps

In the Designer, each Main step runs **per sample** (the default) or **once per batch** (purple).
Iterate takes the rows in groups of *Batch size*. Within a group, a per-sample step runs once for
each row, and a batch step runs once for the whole group.

<Shot name="designer-batch" alt="A step marked once per batch in the Designer" width="narrow" />

The common case: a heater holds two vials at the same temperature. `set_temperature` is marked
once per batch, the batch size is 2, and the table shows what that means:

<Shot name="run-iterate-batch" alt="The Iterate table with a batch size of 2: group dividers, a once-per-batch column, and greyed cells" />

- Groups are cut by row position (rows 1–2, 3–4, …), never by which rows have data, so the lines
  are there before you type anything.
- A batch step's result goes back to every row of its group when the step was given one value per
  row (a plate read keyed by well). Otherwise it shows under the group's first row.

<Aside type="note" title="If and While in a table run">
An If or While block is one unit: a per-sample block runs through for each row in turn and reads
that row's own saved values, so `If absorbance_312 > 1.5` decides on that sample's measurement.
</Aside>
