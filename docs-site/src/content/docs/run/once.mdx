The **Run** page runs the workflow on the Designer's canvas. Its tabs differ only in how the open
values (`#variables`) are supplied. **Once** asks for each value one time and runs one time.

<Shot name="run-once" alt="The Once tab: one field per open value, Preview and Run" />

- A workflow with no open values says *Nothing to fill in* and runs as it is.
- Leave the name blank and the run is numbered: `<workflow> Run #3`.
- A field with a [safety limit](/guide/safety/) shows it, and marks a value outside it at once.

[The live run and the queue](/guide/live-run-and-queue/) covers the run bar, stopping, and what
happens when a step fails. The result is in [Data History](/guide/data-history/).

A saved workflow linked inside the design runs its Main steps only here. Its own Prep and Cleanup
run when it is the whole run: on its own, or as a [stage](/run/stages/).
